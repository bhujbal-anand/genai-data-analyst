# 📊 GenAI Automated Data Analyst & EDA Studio

An automated Exploratory Data Analysis (EDA) dashboard and conversational transformation tool powered by Streamlit, Pandas, Plotly, and local LLaMA 3.2 via Ollama.

## 🚀 Key Features
- **Automated Statistical Diagnostics**: Summaries (`head`, schema types, descriptive statistics, and missing value breakdown).
- **One-Click Business Insights**: Generates executive summaries, strategic trends, and anomaly detection using local LLM inference.
- **Conversational Multi-Turn Analyst**: Chat with tabular data to execute transformations, filtering, and Plotly charts on the fly.
- **State Version Control**: Tracks applied data modifications with an instant "Undo" capability to restore previous states.
- **Dynamic Slice & Dice**: Sidebar categorical multiselects and numerical interactive range sliders.

## 🛠️ Tech Stack
- **Frontend**: Streamlit
- **Data Manipulation**: Pandas
- **Visualizations**: Plotly Express
- **LLM Engine**: LLaMA 3.2 (via Ollama)
- **Language**: Python 3.10+
